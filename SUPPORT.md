# Support

Use [GitHub Issues](https://github.com/KarmenLoop/karmen-memory/issues) for bugs, questions, and feature requests. Include your operating system, browser, Node version, affected page, and a small reproduction with synthetic data.

The repository supports a local SQLite service, browser console, scoped CLI/MCP clients, and optional HTTPS sharing. It does not provide hosted storage, model-provider configuration, or verified native integrations for every catalog tool.

Read [Getting started](docs/getting-started.md) for local setup and [Integration](docs/integration.md) for client setup and service contracts. Sensitive findings follow [SECURITY.md](SECURITY.md).
