# Support

Use [GitHub Issues](https://github.com/KarmenLoop/karmen-memory/issues) for bugs, questions, and feature requests. Include your operating system, browser, Node version, affected page, and a small reproduction with synthetic data.

The repository currently supports running the console prototype, exploring the design, and using the portable design skill. It does not provide a hosted memory service, a production database, paid-model configuration, or verified adapters for the listed tools.

Read [Getting started](docs/getting-started.md) for local setup and [Integration](docs/integration.md) for the remaining service contract. Sensitive findings follow [SECURITY.md](SECURITY.md).
