# KARMEN Memory 使用指南

[English](tutorial.en.md) | 简体中文 · [首页](../README.zh-CN.md)

本指南对应 **v0.2.0** 本地服务 Alpha。应用界面为中文，说明文档提供中英文。

## 下载与启动

runtime ZIP 包含构建后的界面和服务源码；source ZIP 用于开发；技能另有独立 ZIP。完整比较 SHA256SUMS 对应文件的哈希，macOS 使用 `shasum -a 256 FILE`，PowerShell 使用 `Get-FileHash -Algorithm SHA256 FILE`。

需要 Node 22.16+ 和 npm。runtime 目录运行 `npm ci`、`npm start`，打开 `http://127.0.0.1:4318`。source 包启动前还要运行 `npm run build`。仅用静态服务器不能提供 API。局域网另外需要支持 `req -addext` 的 OpenSSL。Windows 运行尚未验收。

## 创建并检索事实

创建一条合成事实，例如“提交信息使用英文”，项目填写 `My Project`，选择类型、来源依据与本机/共享范围。搜索标题，核对相同编号和版本。编辑、刷新并查看旧版本；收藏、归档、恢复，检查每个状态。归档后退出检索，历史仍保留。

提炼使用明确句子规则，检索使用多语言词项匹配，都不调用模型。在记忆提炼页面输入明确要求，核对候选、依据与适用条件后审核。替换会归档旧事实并关联新编号；并发旧版本提交会冲突，不会静默覆盖。

## 配置另一客户端

在 Agent 接入创建具体项目的只读凭证。将令牌保存在权限为 0600 的私有文件，设置 `KARMEN_MEMORY_TOKEN_FILE`，执行 `node bin/memory.mjs search "提交" --project "My Project"`，对照页面中的编号。读写凭证可以提交候选，但不能审批。CI 只能使用具体项目的只读凭证。

[接入说明](integration.md) 提供 MCP stdio 模板和 HTTP 合同。本仓库 CLI 是记忆客户端，不是 Koder CLI。实际宿主配置需分别接入验证。`karmen-memory` 技能指导实际检索和提议；`shared-memory-console` 指导界面设计。安装时保留完整目录和许可证。

## 配对电脑

开启 HTTPS，共享公开证书，通过可信渠道复制并核对指纹，再生成 5 分钟内有效的一次性配对码。在另一台电脑按页面命令使用 `--ca FILE` 配对。私有客户端配置不会覆盖已有文件。仅能访问范围为全设备、项目获准的事实。撤权后下一次请求被拒绝；关闭共享或正常退出服务会关闭监听。主节点必须在线，本版没有离线副本。

## 备份、升级与排错

JSON 用于新增式转移事实（2 MB、最多 5000 条），SQLite 快照保留完整历史和审计。导入先校验完整文件，跳过同项目相同内容。旧原型记录需明确确认。[入门说明](getting-started.md) 描述完整快照恢复：先停止服务，完整保留旧数据库与 WAL，再替换。

升级前创建私有快照、保留旧应用，在隔离数据目录验证新版本。不要覆盖运行中的数据库，也不要尝试不支持的结构降级。记忆缺失时检查 `KARMEN_MEMORY_HOME`、项目范围和归档状态；连接失败时核实实际进程与本机端口。会话过期可重新连接。写入丢失回执时先查看调用记录与候选，CLI 可使用相同幂等键重放原请求。

实际宿主、两台实体电脑、安装包、语义模型、独立安全审查和模型成本收益，仍需分别验收。详见[验收记录](validation.md)。
