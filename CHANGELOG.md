# Changelog

## 0.2.0 — 2026-10-23

Local service alpha.

- Replaced sample records and browser-only mutations with a real SQLite service, transactional revisions, candidate review, and audit history.
- Added project-scoped bearer credentials, read-only and CI policy enforcement, pause, and revocation.
- Added independent CLI and MCP stdio clients, with reviewed proposals and idempotent writes.
- Added explicit-sentence extraction and multilingual lexical retrieval, with evidence and matching reasons.
- Added optional HTTPS sharing, public certificate verification, one-use expiring pairing, and device access restricted to shared facts.
- Added atomic JSON import, current-fact export, consistent SQLite snapshots, and restart verification.
- Replaced illustrative savings with actual query observations and explicitly user-recorded cost samples.
- Added the runtime memory skill, integration tests, and current desktop/narrow-screen captures.

Installed native hosts, physical two-computer acceptance, offline replication, semantic models, native installers, and measured model savings remain outside the verified alpha.

## 0.1.0 — 2026-10-22

Initial public prerelease.

- Added nine administration pages for shared personal memory.
- Prioritized Koder, Koder CLI, and Cursor across the overview, tool page, and picker.
- Added browser persistence, memory correction and lifecycle actions, candidate review, keyword retrieval, and simulated access and pairing flows.
- Preserved validated lifecycle and provenance fields on JSON import and kept view tabs independent from type filters.
- Added desktop and narrow-screen layouts, the portable design skill, public documentation, third-party notices, and build verification.

Real memory-service adapters, automated extraction, authenticated LAN sync, semantic retrieval, and measured savings are outside this prerelease.
